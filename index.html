What is a Computer?

A computer is an electronic device that accepts data as input, processes the data according to instructions, stores information, and produces results as output.

Computers are used in schools, offices, hospitals, businesses, and homes. They help people perform tasks faster, communicate, solve problems, and access information.

Basic Parts of a Computer

🖥️ Monitor

The monitor is an output device that displays text, pictures, videos, and other information.

⌨️ Keyboard

A keyboard is an input device used to type letters, numbers, and commands.

🖱️ Mouse

A mouse is an input device used to point, click, select, and move objects on the screen.

⚙️ CPU

The Central Processing Unit (CPU) executes instructions and performs calculations for the computer.

Importance of Computers

📚 Education

Computers help students research, study online, and complete assignments.

💼 Business

Computers help businesses manage records, finances, and communication.

🌐 Communication

Computers allow people to communicate through email, messaging, and video calls.
